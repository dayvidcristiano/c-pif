a) x = 0 é uma atribuição, não uma comparação. x passa a valer 0, a expressão vale 0 (falso) e o bloco do if nunca executa (executa o else, se houver).

b) Qualquer valor diferente de zero é verdadeiro e zero é falso, seja inteiro ou real.
